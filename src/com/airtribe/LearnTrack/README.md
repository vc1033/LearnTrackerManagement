Project Description :-

It is a Leaning Tracker management System which helps the user to add Students and Courses and to enroll the students into a course.
It facilitates the user with following services :-
  View Students
  View Courses
  Add Student 
  Add Courses
  Activate and Deactivate Courses
  Deactivate Students
  Enroll students into Courses
  View Enrollments
  Get enrollment by Student Id.

How to compile and run :- 

  Directly run the Menu class after navigating to ui.
  
Using CommandLine :
  cd src
  javac com/airtribe/LearnTrack/**/*.java
